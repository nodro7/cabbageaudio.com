`listBox` creates a scrollable list of items which users can choose from. By default a single click highlights an item without sending anything to Csound, and a double-click sends the index of the highlighted item to Csound on the widget's channel. Set `singleClick` to `true` to send the selection on a single click instead.

## Csound Usage

The `listBox` returns the index of the selected item along with a k-rate trigger value. By default the value is sent on double-click; when `singleClick` is `true`, it is sent on every single click. The trigger value will be 1 for one k-cycle when an item is selected, then return to 0. Read it with the `CabbageNumTrig` struct form of `cabbageGetValue`:

```csound
sel:CabbageNumTrig = cabbageGetValue("note")
if sel.trig == 1 then
    event("i", "Tone", 0, 1, sel.val)
endif
```

Set the channel `"type"` to `"string"` to receive the selected item text instead of its index:

```json
"channels": [{"id": "presetCombo", "range": {}, "type": "string"}]
```

```csound
sel:CabbageStrTrig = cabbageGetValue("presetCombo")
if sel.trig == 1 then
    event("i", "LOAD_PRESET", 0, .1)
endif
```

A string channel carries text, persists through session saves, and is excluded from DAW automation.
