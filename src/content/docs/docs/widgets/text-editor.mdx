`textEditor` creates a multi-line text area inside the instrument. The initial text is set with the `label.text` property.

:::note
The `textEditor` is a display and editing surface only. Its edited contents are not currently sent to Csound and it does not load a file automatically. Use `cabbageSet` on the label if you need to replace the text from Csound.
:::

## Example

```json
{
    "type": "textEditor",
    "bounds": { "left": 10, "top": 10, "width": 400, "height": 240 },
    "label": { "text": "Initial text shown in the editor" }
}
```
