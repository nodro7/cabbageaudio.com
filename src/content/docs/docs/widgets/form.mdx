`form` creates the main application window. The default values for size are 600x300. There can only be one form per instrument, and it has the unique channel name of `MainForm`. The `caption` property will only be displayed when running an instrument as a standalone application.

:::note
Configuration properties like `pluginId`, `channelConfig`, `enableDevTools`, `logger`, and `package` have been moved to the top-level of the Cabbage JSON structure. See the [widgets overview](/docs/widgets/overview/) for more details.
:::

### Channel

<Channel />

The form's channels report mouse activity across the whole instrument window while the instrument is running in performance mode. They are not sent while the interface is being edited. This makes the form the place to put global gestures such as scrubbing, mouse-following effects, or detecting when the pointer leaves the interface.

```json
"channels": [
    { "id": "mouseX", "event": "mouseMoveX", "range": { "min": 0, "max": 1 } },
    { "id": "mouseY", "event": "mouseMoveY", "range": { "min": 0, "max": 1 } },
    { "id": "mouseLeft", "event": "mousePressLeft", "range": { "min": 0, "max": 1 } },
    { "id": "mouseRight", "event": "mousePressRight", "range": { "min": 0, "max": 1 } },
    { "id": "mouseInside", "event": "mouseInside", "range": { "min": 0, "max": 1 } }
]
```

`mouseMoveX` / `mouseMoveY` and `mouseDragX` / `mouseDragY` are normalised to the form bounds and scaled into each channel's range. `mouseInside` sends the channel maximum when the pointer enters the form and the minimum when it leaves. Press channels send `1` on press and automatically return to `0` on release; a matching `mouseReleaseLeft` / `mouseReleaseRight` / `mouseReleaseMiddle` event is optional and only needed when the release should use a separate channel id. Because the form covers the whole window, its left-click (`valueChanged`) and mouse press channels report clicks anywhere in the interface, including clicks on other widgets.

:::note
When a `mousePressRight` channel is present, the form suppresses the browser context menu in performance mode so right-button presses can be used by the instrument.
:::
