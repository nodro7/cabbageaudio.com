Cabbage 3 is a framework for audio software development. You write an instrument in Csound 7, give it an interface with the built-in widgets or with your own HTML, CSS and JavaScript, and export it as a plugin from VS Code.

New here? [Install Cabbage 3](/install/) first, then start with [Using Cabbage 3](/docs/using/overview/). Coming from Cabbage 2? [Import an instrument](/docs/using/importing-cabbage-2-instruments/) and read [what is new in v3](/docs/whats-new/).
